# SHRUNK SUDOKU
<img src="" width="400px">

## WHAT IS IT?
classic sudoku game shrunk under 3kb runs as a compliant URI in your browsers address bar as a one liner. solve the sudoku puzzle, you get only 5 lifes if you lose them Game Over.

## WHAT WAS IT LIKE MAKING THIS?
it was a fairly easy game the logics is pretty easy, i did the execution quickly. later i used google font which made it look better also i added game over text and restart button which wasnt there before, and at the end i addded sound to it.
